    Good to know

    Will my tasks still be here after I refresh?

    Yes, when your browser allows local storage. Your list is saved automatically on this device and in this browser. Clearing site data removes it, and a private browsing window may erase it when you close that window.

    Why did I get an error when adding a task?

    A task needs a description. Empty entries and spaces alone are not accepted. Write a short task using no more than 120 characters, then select Add task again.

    Where did my task go after I completed it?

    If you are viewing Active tasks, completing one removes it from that view. Select Completed or All to find it. Uncheck it if you want to make it active again.

    Can I get a deleted task back?

    Deleting removes the task from this list. There is no undo button, so use the completion checkbox if you want to keep a record of what you finished.

    Will my list sync to another browser or phone?

    No. Each browser keeps its own list on its own device. This simple task manager does not have an account or a synchronization feature.
